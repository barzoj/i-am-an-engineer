# HeyGen API credits vs the $49 Pro plan

## Summary

HeyGen API credits are a **standalone** purchase at platform.heygen.com. A Creator/Pro/Business web subscription does **not** fund the API. Automating `iae twin` / `iae generate` needs an API key and a PAYG API credit wallet.

## Gotchas

1. Paying for Pro and wondering why the CLI 401s → create an API key and buy API credits separately.
2. MCP OAuth billed to web subscription credits → fine for a first test; production should use the API key.
3. Free API credits ended Feb 2026 → budget PAYG before rendering Avatar V retries.
