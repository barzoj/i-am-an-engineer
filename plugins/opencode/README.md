# OpenCode plugin

Exposes `iae_run` (passthrough to the `iae` CLI) and registers the fal MCP server when `FAL_KEY` is set.

```bash
opencode plugin add 'github:barzoj/i-am-an-engineer#main::path:plugins/opencode'
```

Install the CLI separately: `uv tool install git+https://github.com/barzoj/i-am-an-engineer`.
